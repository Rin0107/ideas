# 夢日記SNS — 起きてすぐの夢の断片を残し、ほかの人の夢も眺める

## 最重要: セキュリティと個人情報 (持ち主の指定、2026-11-26)
持ち主:「こういう投稿できる系はセキュリティ対策と、個人情報の扱い（利用規約など）、が超重要です。ここをちゃんとやることを最重要なチケットにする」

- **計画はこれを最優先の task にする** (最初の版の計画で、ほかの機能の task より先に作る)。ここが全部済むまで、誰でも使える状態で公開しない (ship しない)
- **利用規約** (画面からいつでも読める): 書いてはいけないこと (自分や他人の名前・住所・電話・メール・学校や勤め先・SNS の ID など個人が分かること、誹謗中傷、違法な内容、宣伝)、運営ができること (投稿の非表示・削除、利用の停止)、免責、使える年齢、規約を変えるときの知らせ方
- **プライバシーポリシー** (画面からいつでも読める): 集めるもの・集めないものの一覧 (このアプリの「守り」の欄と同じ)、使い道、置く場所 (Cloudflare)、残す期間と消え方、第三者に渡さないこと、問い合わせ先
- **同意**: 初めて使うときに、規約とポリシーへの同意を 1 回だけもらう (読めるリンクつき)。変えたときはもう一度
- **個人情報を書かせない仕組み**: 送る前に、電話番号・メールアドレス・URL・SNS の ID・住所らしいものを見つけたら止める (端末とサーバーの両方で検査する)
- **セキュリティ**: 入力は全部検査して上限をかける、生の HTML を差し込まない・CSP、Origin の検査、送る回数の上限 (同じ人・同じ回線)、機械的な大量投稿の対策、セキュリティのヘッダ、依存の脆弱性の検査、ログに投稿の中身や IP を残さない
- **テスト**: 上のどれも受け入れテストで確かめる (個人情報らしい文は送れない、上限を超えると止まる、規約に同意しないと投稿できない、など)。誰のデータに届くかの仕様とテスト (認可) は機能を足すたびに
- **消す**: 自分の投稿は自分でいつでも消せて、消したら本当に消える (残る期間があればポリシーに書く)
- **問い合わせ先** (持ち主の決定、2026-11-26:「問い合わせフォームにしよう」): アプリの中の問い合わせフォーム。持ち主の名前・メールは公開しない。返事が要る人だけ返信先を任意で書く
  - 届け先は、工場のアプリと分けた問い合わせ専用の非公開 repo (例 `wakuwaku-inbox`) の issue。持ち主は GitHub の通知で受け取る
  - 間違って公開されないように: issue を作る前に毎回その repo が非公開かを確かめ、公開なら送らずに止める (持ち主:「まちがえて公開されるとかがちょっとこわい」)。工場はこの repo の公開・設定を変えない
  - issue を作る権限は、その repo の issue だけを書ける GitHub App。鍵は Cloudflare の秘密の設定に置く (手元に置かない)。repo と App を作るのは持ち主の許可を取ってから (wk human)
  - 問い合わせの本文に IP などを足さない。フォームにも送る回数の上限

## 概要
その日見た夢を、断片の一言からでも投稿して保存し、自分の夢日記にできる。残した夢はふだんは自分だけのものだが、見せたい夢だけを「みんなに公開」すると、新着の流れに並び、ほかの人の夢も眺められる。持ち主の依頼で作る主力のアプリ (2026-11-26、focus)。

## わくわくポイント
起き抜けの「なんか駅で走ってた」程度の断片でも、10 秒で残せる。あとで日記を開くと、忘れていた夢が並んでいて「こんな夢見てたのか」と驚ける。公開の流れを開くと、知らない誰かの不思議な夢が次々に流れてきて、「見たことある」「こわい」「ふしぎ」のスタンプで共感できる。同じような夢を見ている人がいると分かるのが楽しい。

## シーン
朝、布団の中でアプリを開き、「海の上の学校。先生が猫だった」と打って保存 (公開しない)。昼休みに日記を見返し、面白かった夢だけ「みんなに公開」にする。夜、新着の流れを眺めて、他人の夢に「見たことある」を押す。

## 体験の核
1. 起き抜けに最短で残せる (開いてすぐ入力欄。断片の一言で保存できる。あとで書き足せる)
2. 自分の夢日記として見返せる (日付ごと。キーワードで探せる)
3. 投稿ごとに公開を選べる。既定は自分だけ。公開した夢は新着の流れに出て、決まったスタンプだけで反応できる (コメントはない)

## ターゲット
夢をよく見る人、夢日記をつけたい人、他人の夢の話が好きな人。誰でも登録できる一般公開。

## マネタイズ
なし。

## 差別化ポイント
夢日記アプリは自分だけで閉じて続かず、SNS は夢を気軽に書く場所ではない。「既定は自分だけ、見せたい夢だけ公開」と「スタンプだけの反応」で、断片でも気軽に残せて、ほかの人の夢を眺める楽しみが続ける理由になる。

## デザイン (持ち主の指定、2026-11-26)
持ち主の回答:
> 夢日記SNS欲しい。その日見た夢を断片でも投稿・保存して日記にできて、ほかの人のも見れる感じで
> 公開範囲: 投稿ごとに選ぶ / 見方: 新着の流れ / 反応: スタンプだけ / 使う人: 誰でも (一般公開)

決まったこと (作るときの基準):
- **公開は投稿ごと**: 既定は自分だけ。「みんなに公開」は投稿ごとに選び、あとから戻せる (非公開に戻すと流れから消える)
- **日記から編集と公開範囲の変更** (持ち主のコメント、2026-11-26:「内容の編集と公開範囲の変更がかのうにしておいて」): 日記の夢をタップすると下から編集のシートが出て、文の直し・公開範囲 (自分だけ・みんなに公開) の切り替え・消すができる
- **使い方を文字で説明しない** (持ち主:「文字で説明するんじゃなくてUIで説明するようにして…スマホに慣れてるユーザーは基本タップして動作を確認する」): 「なおす」のようなリンクや説明の文を置かず、触れば分かる形にする。ボタンの言葉は押した結果が分かるもの (書く画面は公開範囲に合わせて「日記に残す」/「残して公開する」)
- **アカウント** (持ち主:「アカウント設定はどこから？」): 日記の右上に自分のユーザー名の頭の字の丸。タップすると下からシート: ユーザー名 (タップしてその場で変える)・地域・ミュートしたユーザー・データをダウンロード・パスキー・アカウントを削除
- **言葉は一般的な名前** (持ち主:「呼び名って何やねん。一般的な名称を使ってください」): 造語を作らず、ほかのアプリでよく使う言い方にする。項目の補足の説明文も置かない
- **夢の文が主役** (持ち主:「絵文字がもっと目立たないのがいい。あくまで日記の投稿がメインになってほしい」): スタンプは背景なし・小さく・薄い色。自分が押したものだけ色が付く
- **スタンプ**: 絵文字 (持ち主:「スタンプは絵文字にしよう。githubのreactのイメージ」)。👀 見たことある・😨 こわい・🌀 ふしぎ・✨ いいな。夢の下は「絵文字 + 数」の丸で、言葉は画面に出さず説明 (title) と読み上げだけ。夢の下の「＋」で 4 つの絵文字の棚が開き、押すと +1 で色が付く。もう一度押すと取り消し。1 つの夢に違う種類をいくつでも押せる。まだ誰も押していないスタンプは棚を開くまで出さない
- **見方は新着の流れ**: 公開された夢が新しい順に並ぶ。フォロー・おすすめ・ランキングは作らない
- **反応はスタンプだけ**: 決まった数種類 (例: 見たことある・こわい・ふしぎ・いいな)。自由な文字のコメント・DM は作らない
- **誰でも登録できる**: 知らない人どうしが見る前提で、守り (下) を最初から入れる
- **色は夜と夜明け** (持ち主のコメント、2026-11-26):「ダークモードを基本、朝の時間（日の出以降はちょっと明るい、日の出の色のイメージ）なUIがいいな」。基本は暗い夜の色 (モチーフなし)。日の出のあとは藍から桃・橙の夜明けの色で少し明るく。日の出の時刻は端末の中で計算し、位置はサーバーに送らない (地域は自分で選ぶか端末の時間帯から)。UI モックの案 D
- **ホームに追加したら iPhone のアプリのように** (持ち主:「kisekaeと同じようにiPhoneのあぷりっぽくホームに登録したときのUIも最初っから作っておいて」): 最初の版から入れる
  - manifest (display: standalone、name・short_name は「夢日記」、start_url・scope は ./、background_color と theme_color は夜の色)、apple-touch-icon (180px)、apple-mobile-web-app-capable・apple-mobile-web-app-title・apple-mobile-web-app-status-bar-style (暗い画面なので black-translucent)、viewport-fit=cover
  - 中身はステータスバーとホームバーに重ならない (env(safe-area-inset-*) で上下左右をあける。kisekae-closet #58 で上部が重なった)。下のタブはホームバーの上に置く
  - 夜と夜明けで theme-color も変える (ステータスバーの地の色が画面とそろう)
  - アイコンは夜明け前の空の色の上に、小さな月か朝日。ホーム画面で文字なしでも分かる形
  - e2e で、iPhone の大きさ (390×844) の standalone 表示で、上下の要素が安全な範囲に収まることを確かめる

## 守り (docs/DESIGN-v3.md §10)
- ログインはパスキーだけ。パスキーに名前を付けさせない (持ち主の指定、2026-11-26。端末の一覧にはアプリの名前で出る)。メール・パスワード・名前を持たない。サーバーにあるのはランダムな利用者 ID・公開鍵・使った回数
- 公開した夢に出るのは、自動で付くランダムなユーザー名だけ (変えられる。本名を求めない)。利用者 ID は画面にも API にも出さない
- 夢は文字だけ (写真・音声・リンクの自動展開なし)。1 件の長さに上限をかける。生の HTML を差し込まない
- 他人が読めるのは「公開」にした夢と、そのスタンプの数だけ。非公開の夢・誰がスタンプを押したかは本人以外に届かない
- **持ち主の許可 (2026-11-26)**: 雛形の「自分のデータは本人だけ」を、このアプリでは「公開にした夢 (本文・日付・ユーザー名) とスタンプの数は、ログインした誰でも読める」に広げてよい。そのために spec/Access.tla・src/worker/db.ts・migrations/ を変えてよい (守りのレビューを通す)。非公開の夢・誰がスタンプや通報をしたか・利用者 ID は、これまで通り本人以外に届かない。これを超える広げ方は持ち主に聞く
- 荒らし対策: 公開の夢に「通報」ボタン。一定数の通報で自動的に非表示にし、持ち主が確かめる。自分の流れから特定の人を見えなくできる (ミュート)。投稿とスタンプには回数の上限をかける
- 自分の夢・アカウントはいつでも全部消せる (消すと公開の流れからも消える)。書き出しもできる
- 外部のスクリプト・解析・広告を入れない
