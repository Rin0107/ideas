# DATA — このアプリが持つ情報

このアプリは**重要な情報を持たない**。下の表にないものは、どこにも保存しない。
ブラウザに何かを置くときは、先にこの表を更新する (reviewer と CI が照らし合わせる)。

## サーバー

なし。本番は静的ファイルだけで、サーバーの処理も保存の場所もない。

## ブラウザの中だけ (localStorage)

| 何を     | キー              | なぜ     |
| -------- | ----------------- | -------- |
| 訪問回数 | `{{NAME}}:visits` | 雛形の例 |

## 持たないもの

アカウント・メールアドレス・パスワード・名前・住所・電話番号・IP アドレス・User-Agent・位置・Cookie・支払い情報・解析ツールのデータ。
