# 評価 9: Rin0107/kisekae-closet (v0.9)

- 日付: 2026-11-19
- 結論: **iterate** — 主力のアプリなので drop にせず磨き続ける (体験の核が本番で動かない)
- 核が動く: false / わくわく 2 / 品質 3
- 一番の弱点: 長袖とアウターの袖がまだ腕と違う角度の板として離れて付き、手が袖の途中から突き出て台の端で切れるので、一番見せたい冬のコーデが『自分が着ている』絵にならない

## まとめ
脱ぐ操作と天気なしで決める操作は本番で動き、守りも問題なし。ただし goal の『袖が腕と同じ角度で沿い台の中に収まる』は半袖でしか届かず、長袖とアウターは紙の着せ替えのまま。

## バグ
- 長袖トップス・アウターの袖が腕より 15〜25° 立った角度で置かれ、袖と身ごろのあいだに腕の肌が見え、手が袖の途中から突き出る (翼・板に見える)。袖が真下に垂れた長袖でも回すのは 12° ほど。半袖は腕に沿う
- 長袖・アウターの袖の先が台からはみ出して切れる (1280px でアウター左右約 36px・長袖 7〜9px、360px でアウター約 25px)
- ハンガーにかけて撮れと案内するのに、写真のハンガーのフックが切り抜きに残り、アバターの顔・首の上に縦の線として出る
- 天気が読めないと、おすすめは何も着せない (手で着せれば決められる)
- Permissions-Policy の bluetooth が Chrome で『Unrecognized feature』の警告を出す (v0.7 から残る。security.ts は守りの部分)
- アカウントを作る e2e の 4 件 (AC-44・45・46・47 を含む) は、https の BASE_URL だと test.skip になり、本番では AC を確かめられない。手元の Playwright 1.65 は chromium-1254 を探し、nix の 1248 とは symlink を作らないと動かない
