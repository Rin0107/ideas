# 評価 5: Rin0107/kisekae-closet (v0.5)

- 日付: 2026-11-19
- 結論: **iterate** — 主力のアプリなので drop にせず磨き続ける (体験の核が本番で動かない)
- 核が動く: false / わくわく 3 / 品質 4
- 一番の弱点: アバターは 3D になったが、服が四角い写真を体より細く重ねるだけで脇や首から下着がのぞき、腕と袖もずれるので「自分が着ている」絵に見えない

## まとめ
天気は再読み込みで 0.1〜0.4 秒、服を着た絵も 0.35 秒以内に出て、今日の画面・着せ替え・スタンプ・先の日のコーデ・テーマまで本番で通しで動く。服をしまう画面の CSP 違反 (実害なし・直すのは 1 か所) で core_works は false、服の重なりの粗さがわくわくを下げている。

## バグ
- [security] 服をしまう画面で写真の下見の blob: URL を cutout.ts の fetch() が読もうとして CSP の connect-src に止められ、コンソールに CSP 違反が出る (下見が切り抜かれず白い背景のまま)
- 切り抜きが白い背景と一緒に白い服まで消し、白シャツが細い線だけになる (棚でもアバターでも)
- 服の写真が胴より狭く、両脇・首元・腰から白い下着がのぞく。袖が横に張り、斜め下に開いた腕と合わない
- 再読み込み直後、服が届くまでの約 0.1〜0.3 秒、アバターが下着姿でゲージが「寒い」になる
- カレンダーで選んだ日の背景色が凡例の「今日とほぼ同じ」と同じピンクで紛らわしい
- 天気の行が「雨 / 0mm」の途中で折り返す
- 「アカウントと全データを消す」のあとも localStorage に city と theme が残る
