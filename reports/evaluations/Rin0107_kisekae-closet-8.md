# 評価 8: Rin0107/kisekae-closet (v0.8)

- 日付: 2026-11-19
- 結論: **iterate** — 主力のアプリなので drop にせず磨き続ける (体験の核が本番で動かない)
- 核が動く: false / わくわく 2 / 品質 3
- 一番の弱点: 着せた服の袖が腕と違う角度で翼のように張り出し、前を開けたアウターも体に貼った板に見えて、『自分が着ている』絵にならない

## まとめ
登録・おすすめ・決める・カレンダー・先の日の予定は本番で通り、守りも問題なし。ただし天気なしでは決められないバグが残り、goal の『袖が腕に沿う』も達成されず、着せた絵はまだ紙の着せ替えのまま。

## バグ
- 天気が読めず前回の予報も端末にないと、服を手で着せても『これに決めた』が出ない (v0.7 から残る。App.tsx:343 が weather を条件にしている)
- 長袖・アウター・T シャツの袖が A の字の腕に沿わない: 腕より 30〜40° 外へ張り出し、広げた T シャツの写真では袖が上向きに回る。袖と肩のあいだに隙間ができ、腕に沿って細い線のかけらも出る
- 袖の先が台の端で切れる (1280px でも 360px でも)
- 着ている服を脱ぐ方法がない (takeOff を画面のどこからも呼んでいない。着ている服をもう一度押しても変わらない)
- 白い服を白い背景で撮ると切り抜けず、写真全体の白い四角が体にかぶる。身ごろの切れ目に縦の線が出て、切り抜けなかったことも知らせない
- 幅 360px で『決めた!』のスタンプが右のくつに重なって隠す
- Permissions-Policy の bluetooth が Chrome で『Unrecognized feature』の警告を出す (v0.7 から残る。security.ts は守りの部分なので人に頼む必要がある)
- e2e のアカウントを作る 3 件は、本番に向けると test.skip で必ず飛ばされ、本番では AC が確かめられない。手元の Playwright 1.65 は nix の chromium-1248 と版が合わず、そのままでは起動しない
