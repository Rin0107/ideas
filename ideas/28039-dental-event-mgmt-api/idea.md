# 歯科医院向けイベント運営管理ツール(API提供型)

## 概要
歯科医院が開催するイベント・体験会の告知・申込・当日運営を一元化するツール。機能をAPIとして提供し既存システムへ組み込める形にした派生版。

## 課題
歯科医院ではイベントのたびに告知・申込集計・リマインドを手作業で行っている。

## 解決策
申込ページの自動生成から出欠管理・アンケート回収までを1つで完結させる。

## ターゲット
歯科医院のイベント担当者。

## マネタイズ
イベント数または参加者数に応じた課金。

## 差別化ポイント
歯科医院のイベント形式に合わせた申込フォームテンプレート。自社システムや他SaaSへの組み込みやすさ。

## Go実装方針
イベント管理APIと通知配信を持つGoサーバー。
