# 動物病院向けヒヤリハット報告ツール(API提供型)

## 概要
動物病院の現場で起きたヒヤリハット・事故をスマホから即時報告・集計するツール。機能をAPIとして提供し既存システムへ組み込める形にした派生版。

## 課題
動物病院では現場の小さな異変が報告されず、大きな事故につながっている。

## 解決策
スマホから写真付きで簡単に報告でき、傾向分析で再発防止策につなげる。

## ターゲット
動物病院の安全管理者・現場スタッフ。

## マネタイズ
従業員数に応じた月額課金。

## 差別化ポイント
報告のハードルを最小化した入力フロー設計。自社システムや他SaaSへの組み込みやすさ。

## Go実装方針
報告受付APIと集計ダッシュボードを持つGoサーバー。
