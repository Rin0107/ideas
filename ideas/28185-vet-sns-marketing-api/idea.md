# 動物病院向けSNS運用支援ツール(API提供型)

## 概要
動物病院のSNS投稿の作成・予約・効果測定を支援するツール。機能をAPIとして提供し既存システムへ組み込める形にした派生版。

## 課題
動物病院ではSNS運用の重要性は分かっていても、ネタ出しと投稿の継続ができない。

## 解決策
動物病院向けの投稿テンプレートとネタカレンダーを提供し、予約投稿と効果測定まで行う。

## ターゲット
動物病院の経営者・広報担当。

## マネタイズ
アカウント数に応じた月額課金。

## 差別化ポイント
動物病院業界で反応の良い投稿パターンのテンプレート集。自社システムや他SaaSへの組み込みやすさ。

## Go実装方針
SNS API連携と投稿スケジューラを持つGoサーバー。
