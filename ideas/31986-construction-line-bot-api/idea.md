# 建設会社向けLINE自動応答ボット(API提供型)

## 概要
建設会社へのよくある問い合わせにLINE上で自動応答するボット。機能をAPIとして提供し既存システムへ組み込める形にした派生版。

## 課題
建設会社では営業時間や空き状況などの定型問い合わせ対応に時間を取られている。

## 解決策
よくある質問への自動応答と、複雑な問い合わせのスタッフ引き継ぎを提供する。

## ターゲット
建設会社の経営者・受付担当。

## マネタイズ
月額SaaS課金。

## 差別化ポイント
建設会社の定型質問セットを学習済みで導入即日から使える点。自社システムや他SaaSへの組み込みやすさ。

## Go実装方針
LINE Messaging API連携と応答エンジンを持つGoサーバー。
