# Gitリポジトリ部分クローン最適化ツール

## 概要
巨大モノレポの中から開発者が実際に触るディレクトリだけを自動判定してsparse-checkout設定を生成するツール。

## 課題
モノレポのクローンに時間がかかり、CIやオンボーディングの生産性を落としている。

## 解決策
過去のコミット履歴・作業ディレクトリの利用実績を解析し、最適なsparse-checkoutパターンを提案・適用する。

## ターゲット
大規模モノレポを運用する中堅〜大企業の開発チーム。

## マネタイズ
チーム単位のライセンス販売+CI連携時の従量課金。

## 差別化ポイント
手動設定不要で利用実績ベースに自動最適化する点。

## Go実装方針
git logをパースする解析器とsparse-checkoutコマンドを操作するCLIをGoで実装。
