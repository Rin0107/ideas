# 歯科医院向け保険・保証書類管理ツール(API提供型)

## 概要
歯科医院が扱う保険・保証関連書類の期限と更新を管理するツール。機能をAPIとして提供し既存システムへ組み込める形にした派生版。

## 課題
歯科医院では保険・保証の更新期限管理が漏れ、無保険期間が生じるリスクがある。

## 解決策
書類をアップロードすると期限を自動抽出し、更新前にリマインドする。

## ターゲット
歯科医院の総務・管理担当者。

## マネタイズ
管理書類数に応じた月額課金。

## 差別化ポイント
OCRによる期限自動抽出で登録の手間を最小化する点。自社システムや他SaaSへの組み込みやすさ。

## Go実装方針
OCR連携とリマインダーを持つGoサーバー。
