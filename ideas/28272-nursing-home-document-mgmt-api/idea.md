# 介護施設向け書類電子化ツール(API提供型)

## 概要
介護施設の紙書類をスキャン・OCRで電子化し検索可能に保管するツール。機能をAPIとして提供し既存システムへ組み込める形にした派生版。

## 課題
介護施設では紙書類の保管・検索に時間がかかり、紛失リスクもある。

## 解決策
スキャンした書類をOCRで全文検索可能にし、種別ごとに自動分類する。

## ターゲット
介護施設の事務担当者。

## マネタイズ
保管容量に応じた月額課金。

## 差別化ポイント
介護施設で扱う書類種別に特化した自動分類の精度。自社システムや他SaaSへの組み込みやすさ。

## Go実装方針
OCR連携と全文検索インデックスを持つGoサーバー。
