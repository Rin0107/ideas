# 歯科医院向け廃棄ロス削減ツール(API提供型)

## 概要
歯科医院の廃棄・ロスを記録し発生パターンから削減策を導くツール。機能をAPIとして提供し既存システムへ組み込める形にした派生版。

## 課題
歯科医院では廃棄ロスが利益を圧迫しているが、発生原因が記録されていない。

## 解決策
廃棄の品目・数量・理由を簡単に記録し、パターン分析で削減策を提示する。

## ターゲット
歯科医院の店長・現場責任者。

## マネタイズ
月額SaaS課金。

## 差別化ポイント
記録の手間を最小化したスマホ入力フロー。自社システムや他SaaSへの組み込みやすさ。

## Go実装方針
記録APIと集計分析を行うGoサーバー。
