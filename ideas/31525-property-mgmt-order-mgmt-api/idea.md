# 賃貸管理会社向け受発注管理ツール(API提供型)

## 概要
賃貸管理会社の受注・発注をFAXや電話からデジタルに置き換えるツール。機能をAPIとして提供し既存システムへ組み込める形にした派生版。

## 課題
賃貸管理会社ではFAX・電話での受発注に伴う転記ミスと確認の手間が大きい。

## 解決策
Webフォーム・LINEからの受注をデータ化し、発注書の自動生成まで行う。

## ターゲット
賃貸管理会社の受発注担当者。

## マネタイズ
取引件数に応じた従量課金。

## 差別化ポイント
取引先にはFAX併用を許容する段階的移行設計。自社システムや他SaaSへの組み込みやすさ。

## Go実装方針
受発注データ管理と帳票生成を行うGoサーバー。
