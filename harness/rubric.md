# rubric — 選ぶとき・評価するときの採点基準

守りの部分 (エージェントは変えられない)。点は各 1〜5。**根拠を 1 行で書けない点は付けない (3 にする)**。

## select: アイディアの採点 (`wk select --scores`)

候補ごとに、次の JSON を 1 件ずつ (配列で) 出す:
```json
{"idea": "00141-regex-crossword", "wakuwaku": 5, "light": 4, "free": 5, "own": 4, "findy": 4,
 "hardware": false, "sensitive": false, "needs_server": false,
 "data_plan": "解答の記録はブラウザの中だけ。今日の問題は日付から決まるので、サーバーは要らない",
 "stack": "web", "reason": "毎朝 1 問の儀式が作れる。核は交差の検証で、静的ファイルとブラウザで完結"}
```

| 項目 | 5 | 3 | 1 |
|---|---|---|---|
| wakuwaku わくわく | 説明を聞いただけで触りたくなる。触った人が誰かに見せたくなる | 面白いが、一度触れば十分 | 便利なだけ |
| light 軽さ | 体験の核が 10 tick (issue 3〜4 個) で動く | 30 tick でぎりぎり | 30 tick では核まで届かない |
| free 無料で成立 | 静的ファイルだけで成り立ち、鍵の要らない公開 API も使わない | 無料枠に収まるが、人が増えると危ない | 有料のサービス・API が要る |
| own 自分ごと | ユーザーの関心 (Go・TS・IoT・AI エージェント・日本の暮らし) に近い | どちらでもない | 遠い |
| findy 公開実績 | Go / TS のコードとして読み応えがあり、人に見せられる | 普通の Web アプリ | コードの見どころがない |

**必ず除外 (点に関係なく)**:
- `sensitive: true` — 体験の核に、個人を特定できる情報・認証情報・支払い・位置の履歴・健康・他人の情報・未成年の情報を**サーバーに**持つ必要がある。
  「ブラウザの中だけで処理できる」なら false にしてよい。迷ったら true
- `needs_server: true` — 体験の核に、サーバーの処理か保存 (ほかの人とのデータの共有・ランキング・同期・アカウント) が要る。
  工場のアプリは静的ファイルだけで配る。「ブラウザの中・日付や乱数から決まる・URL に載せて渡す」で成り立つなら false
- `hardware: true` — 物・現地・人手 (配送・イベント・店舗) が要る。ソフトだけで完結しない
- 実在の企業・作品・人物のなりすましや、既存の有名な作品の再現になるもの (`hardware` と同じく除外の理由に書く)

`data_plan` は必ず書く。何も持たないなら「なし (すべてブラウザの中)」。

## evaluate: プレビューの採点 (`wk evaluate --scores`)

**作った本人ではない Claude (サブエージェント) が、プレビューの URL (CLI はリリース) を実際に触って** 付ける:
```json
{"core_works": true, "wakuwaku": 4, "quality": 3,
 "bugs": ["スマホ幅で盤面がはみ出す"], "weakest": "解いたあとに何も起きず、達成感が薄い",
 "summary": "毎朝の 1 問は成立している。交差の検証は正しく、10 問中 10 問で一意解"}
```

| 項目 | 基準 |
|---|---|
| core_works | idea.md の「体験の核」が、本番で、説明なしに、最後まで通る。AC のテストが本番で全部通る。どれか欠ければ false |
| wakuwaku | 5: 触ったあと誰かに見せたくなる / 3: 面白いが一度で十分 / 1: 作業をしている気分 |
| quality | 5: 迷わない・壊れない・スマホでも使える・読み込みが速い / 3: 使えるが粗い / 1: すぐ壊れる |
| bugs | 見つけたものを全部。セキュリティの問題 (外部への送信・保存してはいけない情報・CSP 違反) は先頭に `[security]` を付ける |
| weakest | わくわくを一番下げている点を 1 つ (iterate の材料) |

**`[security]` のバグが 1 つでもあれば core_works は false にする** (セキュリティが最優先)。
