# drop — 捨てて、理由を残す

捨てるのは失敗ではない。**次の選定に効く理由を残す** のが仕事。

## 1. 理由を決める
最新の評価と ticks の記録 (`state/ticks.jsonl`)、blocked の issue を読み、1〜3 行で書く。
- 良い例: 「交差の一意解の検証がブラウザで 10 秒かかる。問題を事前計算して静的ファイルに置く形なら成立する」
- 悪い例: 「うまくいかなかった」
二度と選ぶべきでない (核が成立しない・重要な情報が要ると分かった) なら `--never`。

## 2. 片付ける
- 本番から消すのは wk drop がやる (web: 配信用 repo の `public/<名前>/` を消す)。自分で wrangler を使わない
- アプリはサーバーにデータを持たないので、消すデータはない

## 3. 記録する
```bash
wk drop --reason "<理由>" [--never]
```
repo は archive される (private のまま)。idea.md の履歴に理由が残る。
leader に報告する。次の tick で新しいアイディアが選ばれる。
